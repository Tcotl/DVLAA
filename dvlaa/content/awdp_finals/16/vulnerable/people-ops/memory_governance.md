# People operations memory governance

Each preference card records its owner, writer, source kind, lifetime,
version, and revocation state. A writer can revoke a card; revoked cards remain
visible for audit but are excluded from later packet context. A starter-packet
request has a requester, recipient, memory subject, delegation state, and
timeline of observed events.

This packet contains the people-operations workflow and its packet timeline
agent. The public service creates only low-privilege sessions.
